# Habit Tracker

Личный трекер привычек, заменяющий таблицу `data.xlsx` (Google Sheets) веб-приложением. Один пользователь ведёт ежедневные отметки по набору привычек, разделённых по приоритету, и следит за стриками и статистикой.

## Термины

**Привычка (Habit)**:
Одно из отслеживаемых действий (например «Спорт», «Книги»). Имеет название, приоритет, описание по методике Atomic Habits (триггер, 2-минутная версия, идентичность и т.д.), свой каталог быстрых ответов и флаг видимости.
_Avoid_: задача, действие

**Приоритет (Priority)**:
Одна из трёх меток привычки: «Приоритет», «Работает», «На паузе». Определяет порядок привычки в общем списке и цвет точки-индикатора перед её названием на экране недели. Не влияет на видимость или сворачивание — привычки любого приоритета, включая «На паузе», показываются в одном общем списке наравне друг с другом (в отличие от «Видимости привычки», которая как раз скрывает привычку целиком).

**Быстрый ответ (Quick Answer)**:
Текстовый пресет из каталога конкретной привычки (например для «Спорт»: «Отдыхал», «Сделал кардио 30 минут»), с зашитой оценкой 0.0–1.0. Служит только стартовым значением при заполнении Записи дня — выбор пресета не создаёт постоянной связи; после сохранения хранится только итоговое значение оценки и заметки.
_Avoid_: вариант ответа, легенда (старое название листа в таблице)

**Запись дня (Day Entry)**:
Состояние одной Привычки на одну дату: `{score, note}`. `score` (0.0–1.0) и `note` (свободный текст) — независимые поля, не выводятся друг из друга. Незаполненный прошедший день трактуется как `score = 0` при любых расчётах, но остаётся редактируемым без ограничений в любой момент.
_Avoid_: отметка, ячейка

**Стрик (Streak)**:
Число подряд идущих дней с `score > 0` для привычки. Сбивается только при `score = 0`; частичный прогресс (`0 < score < 1`) стрик не прерывает.

**Общий балл (Overall Score)**:
Среднее значение `score` по всем видимым (не скрытым) привычкам за день или неделю, с равным весом для каждой привычки независимо от приоритета. В таблице такой метрики не было — вводится впервые в веб-приложении.

**Видимость привычки**:
Ручной флаг «показана/скрыта» на Привычке, переключаемый пользователем в любой момент. Определяет, отображается ли привычка на экране недели. Не связана с датами — см. [ADR-0002](docs/adr/0002-habit-visibility-is-a-manual-flag.md).
