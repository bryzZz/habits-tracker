# Тема оформления (light/dark) хранится в localStorage, в отличие от доменных данных

[ADR-0003](0003-local-storage-is-a-real-json-file.md) сознательно отказался от `localStorage` для доменных данных (привычки, записи дня) в пользу JSON-файла на диске. Тема оформления — чисто клиентская UI-настройка конкретного браузера, не относящаяся к домену привычек и не предназначенная для переноса в Supabase, поэтому для неё используется обычный `localStorage`: разграничение проходит по признаку «доменные данные, которым нужно пережить браузер» против «настройка отображения этого браузера».

Рассматривалась альтернатива — хранить тему в том же JSON-файле через `DataStore`, но это привязало бы чисто визуальную настройку к домену и к локальному dev-серверу (`localDataApi`) без всякой пользы.
