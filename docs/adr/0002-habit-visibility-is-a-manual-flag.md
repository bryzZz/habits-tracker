# Видимость привычки — ручной флаг, а не даты жизненного цикла

Реальная история в `data.xlsx` показывает, что привычки стартовали в разное время и не все отслеживаются до сих пор (например «Китайский» — с 06.07.2026, «Холодный душ» — только с 20.08.2026, «Французский» перестал заполняться 05.06.2026). Рассматривался вариант смоделировать это явно через `activeFrom`/`activeTo` на Привычке, чтобы экран недели не показывал привычку до её реального старта и после остановки.

Решили не делать так: вместо дат жизненного цикла у Привычки есть простой ручной флаг «показана/скрыта», переключаемый пользователем в любой момент. Привычка, показанная сегодня, отображается на всех неделях, включая прошлые, где для неё просто не было данных — незаполненный день трактуется как `score = 0` (см. глоссарий, «Запись дня»), и это осознанно принятое пользователем упрощение: он берёт на себя ответственность за честность ведения, а не полагается на автоматическую логику дат.

Компромисс: прошлые недели могут показывать «0» там, где привычки на самом деле ещё не существовало, а не «нет данных». Пользователь предпочёл эту простоту точности дат.
