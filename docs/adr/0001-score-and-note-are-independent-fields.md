# Score и note — независимые поля Записи дня

В таблице `data.xlsx` оценка вычислялась формулой из выбранного текста ответа (`INDEX/MATCH` по листу «Легенда»): один текст — одна жёстко привязанная оценка. Пользователю не хватало гибкости — он хотел ставить оценку и писать заметку к дню отдельно друг от друга, не будучи ограничен ровно одним из предустановленных текстов.

Решили: Запись дня хранит `score` и `note` как два независимых поля. Каталог Быстрых ответов по-прежнему существует (по привычке), но используется только как способ быстро предзаполнить оба поля разом — после выбора пресета (или вместо него) оба поля редактируются свободно, и итоговая запись не хранит ссылку на то, каким пресетом (если вообще каким-то) она была заполнена.

Альтернатива — оставить оценку производной от текста (как в таблице) и добавить отдельное поле только для заметки — была отвергнута: пользователь прямо указал, что хочет редактировать оценку независимо от текста, а не только дополнять текст поверх формулы.
