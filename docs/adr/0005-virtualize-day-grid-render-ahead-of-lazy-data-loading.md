# Сетка дней виртуализирует рендер раньше, чем ленивую подгрузку данных

Редизайн экрана недели позволяет пролистывать сетку дней на ±5 лет от сегодня (недели и месяцы — одинаково, стрелочками или скроллом колесом/тачпадом). Это делает рендер всех дней разом в DOM неприемлемым, поэтому сетка использует `@tanstack/react-virtual` для горизонтальной виртуализации — в DOM держатся только видимые ячейки плюс небольшой запас, не весь диапазон.

При этом `DataStore` по-прежнему грузит все данные (`habits` + `entries`) одним запросом при старте — ни диапазонных запросов, ни реальной ленивой подгрузки данных ещё нет. Для дат без записей просто нет ключа в уже загруженной карте, и они рендерятся как обычные пустые ячейки (см. ADR-0002 — незаполненный день трактуется как `score = 0`). Настоящая подгрузка данных по диапазону запланирована отдельной задачей вместе с переходом на Supabase и `@tanstack/react-query`.

Рассматривался вариант отложить виртуализацию рендера до того же перехода на Supabase, чтобы окно рендера и подгрузку данных делать одним куском работы. Отклонили: UI-редизайн (скролл вместо кнопок листания) не обязан ждать миграции на Supabase, а виртуализация DOM и ленивая подгрузка данных — независимые задачи, которые можно и правильно делать раздельно.
