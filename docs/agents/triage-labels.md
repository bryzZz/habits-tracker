# Triage Labels

The skills speak in terms of five canonical triage roles, mapped here to this repo's actual label strings. When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string below. Edit the right-hand side to match whatever vocabulary you actually use.

- **`needs-triage`** → `needs-triage` — maintainer needs to evaluate this issue
- **`needs-info`** → `needs-info` — waiting on reporter for more information
- **`ready-for-agent`** → `ready-for-agent` — fully specified, ready for an AFK agent
- **`ready-for-human`** → `ready-for-human` — requires human implementation
- **`wontfix`** → `wontfix` — will not be actioned
